# DumbJumper

DumbJumper is a physics-based platformer prototype developed using Unity 6.  
This project served as a hands-on learning experience to explore various Unity features, systems, and development workflows.

## Project Demo
https://youtu.be/3K3GBHd4Yb4

## Project Highlights

- Built a state-driven game flow to manage menus, gameplay, and transitions.
- Implemented custom UnityEditor inspector tools to streamline development.
- Switched to Unity's new Input System, utilizing event-based input for smoother control.
- Integrated physics interactions by creating a grappling hook mechanic using Rigidbody dynamics.
- Gained experience working with Unity's physics engine, input management, and editor scripting.

## Tech Stack

| Technology | Description |
